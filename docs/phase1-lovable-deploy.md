# Phase 1 — what to deploy in Lovable

Order matters: deploy migrations first, then the functions. Everything is
additive; the site keeps working while a function or column is still
missing.

## Migrations (SQL)

Deploy these in chronological order:

1. `supabase/migrations/20261114231645_phase1_after_purchase.sql`
   - Adds `tracking_token` (unique, generated by default, backfilled),
     `customer_name`, `total_paid_cents`, `carrier`, `tracking_number`,
     `tracking_url`, `label_url`, `shipment_ref`, `shipped_at`,
     `delivered_at`, `internal_notes` on `orders`.
   - Creates `public.order_events` (admin-only RLS).
   - Creates RPC `public.get_order_by_token(_token text)` — security
     definer, returns only safe fields.
   - Creates helper `public.gen_order_tracking_token()`.
2. `supabase/migrations/20261114232556_uploaded_not_purchased.sql`
   - Adds `uploaded_not_purchased jsonb default '[]'::jsonb` on `orders`
     so the owner email can list "Subidos pero no comprados".
3. `supabase/migrations/20261115121739_get_order_tracking_by_email.sql`
   - RPC `public.get_order_tracking_by_email(_order_number, _email)` so
     `/track` accepts the customer's email as an alternative to the last
     3 phone digits.

## Edge functions

Deploy in any order after the migrations.

1. `create-instant-checkout` *(updated)* — writes
   `uploaded_not_purchased` to new orders (retries without it when the
   column is still missing) and includes `order_number`, `tracking_token`
   and `fulfillment` in the Stripe `success_url` so the client can show
   the order page link.
2. `send-order-confirmation` *(updated)* — owner copy switches to the
   shared layout with the new subject
   `[PEDIDO #264] 20,06 € · envío IT · 5 piezas · PETG`. Customer copy
   uses the per-language template, button goes to
   `/pedido/<tracking_token>`.
3. `send-quote-request` *(updated)* — owner copy switches to the shared
   layout with the new subject
   `[REVISIÓN] 121,01 € · 20 uds TPU · IT · Pietro`.
4. `send-order-status` *(new)* — one function, four templates (in
   production, shipped, ready pickup, delivered + review). Called from
   the admin (Phase 2) and the Packlink webhook (Phase 4).
5. `order-files-zip` *(new)* — admin-only. Streams the order's purchased
   pieces as a `.zip` with clean filenames.

No new secrets for Phase 1. The owner should also redeploy the site
build so the new `/pedido/:token` route, the restyled `/track` (accepts
email) and the Stripe success banner go live together.
