# conv-27 — Order modal redesign (bug fixes + Simple/Advanced split + viewer rewrite)

**Date:** 2026-11-05
**Scope:** Prompt 27 — redesign the order modal (simple + advanced, clean,
trustworthy) + fix the 10 production bugs + procedural materials + viewer
toolbar / Fullscreen / calmer controls + full Playwright audit.
**Branch:** main.

## TL;DR

Two-commit effort. First pass shipped the modal shell, bug fixes, and
Simple/Advanced rebuild. Second pass shipped the viewer:

- Procedural `MeshPhysicalMaterial` per material (PLA / PETG / ABS / ASA /
  Nylon / TPU), canvas-generated noise normal maps shared across instances,
  `RoomEnvironment` loaded through `PMREMGenerator` for lighting, ACES
  filmic tone-mapping, SRGB output.
- Transparent colour applies transmission 0.6 + thickness 2 + roughness 0.15
  on top; "Cualquier color" uses neutral `#9ca3af` grey.
- One soft key light (dir, intensity 0.75) + fill light (dir, 0.3) + env map —
  the gloss / clearcoat / sheen differences now actually read on the mesh.
- Calmer OrbitControls: `rotateSpeed = 0.35`, `dampingFactor = 0.08`,
  `zoomSpeed = 0.6`, `enablePan = false`, polar clamped to `≤ 0.49π` so the
  part never flips under the plate. Slow idle `autoRotate = 0.6` stops on
  first user grab. Cursor flips `grab` → `grabbing` → `grab`.
- Auto-fit: camera placed at `(maxDim/2) / tan(fov/2) * 1.4` so the part
  fills ~71% of the viewport on load (spec target was ~70%).
- Top-right icon toolbar: **Medidas · Reset · Expand** (3 buttons, 28×28,
  slate icons, raised on active). The old `Compare` pill is removed — the
  spec's new toolbar is the 3-button set.
- **Expand** uses the Fullscreen API with a `100vw × 100vh` absolute-overlay
  fallback (`setOverlayFallback(true)`) for iOS Safari where
  `requestFullscreen` rejects. `Esc` exits the overlay via a document
  keydown listener; native `Esc` still handles the real fullscreen path.
- Fires `viewer_expanded { on: boolean }` on both entry and exit.
- Dimensions still render as projected axis labels (red/green/blue) and a
  tidy bottom pill `132 × 61 × 61 mm · 43 g` (one line, pointer-events: none
  so it doesn't fight the canvas).
- Test hook: `window.__stlViewerMaterial` is kept current with
  `{ key, colour, roughness, metalness, clearcoat, clearcoatRoughness,
  sheen, sheenRoughness, transmission, normalMap, normalScaleX }`. Playwright
  asserts the mesh material actually mutates on each material change.

Plus the first-pass changes still in: modal shell 1320 × 860, 60 / 40 split,
Simple / Avanzado toggle, Cantidad stepper, Plazo pills, pinned summary,
colour-picker dropdown, text-link action row, `Tu pieza` header with
filename, 8-locale i18n, `data-modal-open` on `<html>` suppresses floating
widgets, backdrop `bg-black/60`.

### Bugs found by audit (and fixed in this pass)

- **Compare label projected off-screen at the new camera angle.** Was fine
  under old continuous `autoRotate = 1.5` but with calmer controls the point
  `(maxDim/2 + 60, 15, 0)` projected to NDC x ≈ 14, far outside the viewport.
  Compare toggle isn't in the new 3-button toolbar anyway — the `Compare`
  pill and its two viewer tests were removed. The three.js `compareGroup`
  code is now unreachable from UI and can be removed in a follow-up.
- **`showDims` default inverted.** My first viewer rewrite defaulted it to
  `false` (matching the spec hint "toggle the dimension labels") which
  broke `viewer.spec.ts` dim-visible / reset tests. Reverted to `true` to
  match the shipped UX and existing tests.
- **ColourPicker role mismatch in `prompt-25.spec.ts` check 7.** The old
  check assumed swatches were `role="radio"` on the page; they're now
  `role="option"` inside a closed dropdown. Fixed the check to open the
  dropdown first.
- **Qty doesn't change the total on a 20 mm cube** — fully expected, the
  €10 minimum-order rule swallows it. Added a comment and assertion that
  the DOM qty updates, moved price-change assertion to plazo.
- **PETG → PLA swap and PMREM env** both need the `uv` attribute. Added a
  trivial planar projection (`position.xy / maxDim`) so noise normal maps
  tile predictably per face.
