# conv-27 — Order modal redesign (bug fixes + Simple/Advanced split)

**Date:** 2026-11-05
**Scope:** Prompt 27 — redesign the order modal (simple + advanced, clean,
trustworthy) + fix the 10 production bugs listed in the prompt.
**Branch:** main · one commit.

## TL;DR

Shipped the bulk of the modal redesign in a single surgical pass:

- All 10 named bugs fixed.
- Modal shell rebuilt: 1320 × 860 on desktop, 60 / 40 split, opaque backdrop,
  file name next to a renamed `"Tu pieza"` / `"Your part"` header, floating
  widgets suppressed while open.
- Right column: top-of-column `Simple | Avanzado` segmented toggle, 4 Simple
  rows (Material / Color dropdown / Cantidad / Plazo) + `+ Añadir nota` link,
  Advanced keeps every Simple control and adds Calidad / Resistencia /
  Orientación / Soportes / Tamaño.
- Pinned summary sits once at the bottom of the right column. The duplicate
  Setup / Shipping / Total block in the scrolling body is gone.
- Material deltas removed from the material grid (total now updates live);
  colour picker is a closed dropdown that opens into a 2-column swatch grid.
- Guarantee / trust promise collapsed into one 12 px grey line; Review +
  WhatsApp + save-quote + copy-link are now text links, not full-size
  outlined buttons competing with Comprar.
- All new strings translated into es / en / ca / fr / de / it / nl / pt.
- 4 new analytics events typed: `viewer_expanded`, `color_dropdown_opened`,
  `material_more_opened` (renamed from `more_materials_opened`),
  `note_opened`.

## Ship-date calc (for `Thursday 2026-11-05 08:39`)

Reproduced locally with the constants in `src/lib/shipDate.ts`:

```
Now:     2026-11-05 08:39 (Thursday, dow=4)
Cutoff:  14:00 → before cutoff → shift = 0

standard (3 prod days): start=Thu + 2 business days  → Monday  2026-11-09 ✓
express  (2 prod days): start=Thu + 1 business day   → Friday  2026-11-06 ✓
urgent   (1 prod day):  start=Thu + 0                → Thu     2026-11-05 ✓
```

The `"standard order on Thursday 08:39 shipping on Monday"` promise matches
the real constants. Before the fix, we additionally claimed `"lo imprimimos
hoy"` which was true but strongly misread as `"and you get it today"` — now
removed in all 8 locales.

## Material grid relative-delta: how it stays correct

Material row no longer renders deltas. For the Advanced-mode quality +
strength rows, deltas still render — they're computed against the row's
default option (not the current selection) via `optionDeltas.ts`. This is
consistent with the spec's `"relative to the default option of that same
row, never to the current selection"` rule for everything except material.
