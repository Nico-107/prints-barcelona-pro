# modal_actions_r1 — result

**Status:** concluded (early stop)  
**Concluded:** 2026-10-29  
**Reason:** owner decision — sample too small for a statistical winner

## Variants
- **A (control):** Buy Now button + two equal-size outline buttons (Review / WhatsApp)
- **B (buy-first):** Buy Now button dominant, Review and WhatsApp as small text links below
- **C (reassure-then-buy):** reassurance bullet list above Buy Now, text links below

## Decision
Variant B shipped permanently. The owner wants the Buy button dominant, with review and
WhatsApp as secondary/small actions. All XP CSS and holdout tracking removed.

## Notes
The experiment ran for ~9 days (2026-10-20 → 2026-10-29), fewer than the 21-day minimum.
Data was directional but not statistically conclusive. The owner made a judgement call to
stop early and ship B, accepting the lack of a statistical winner.
