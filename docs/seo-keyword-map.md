# SEO keyword map (Conv 6.3)

One primary phrase per indexable URL. No two pages share a primary
phrase. Phrases taken from Semrush and Google Search Console (28-day
window, 13 Nov).

Shape of each row:
- **Primary** — the single query this page should rank for.
- **Secondary** — 2–3 close variants the page should also catch.
- **Pos** — current avg. position in GSC (last 28 d) or "—" if unseen.
- **Do not compete with** — the sibling page that owns a sister term.
