## Rules

1. Each primary query is owned by exactly one URL per language.
2. Removed: `/impresion-3d-barcelona` (301 → `/`) and `/ca/impressio-3d-barcelona` (301 → `/ca/`) — formerly competing with homepage.
3. `impresión 3D en Barcelona` / `servicio de impresión 3D Barcelona` → **`/`** only.
4. `3d printing barcelona` / `3d print barcelona` → **`/3d-printing-barcelona`** only.
