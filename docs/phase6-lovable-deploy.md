# Phase 6 Deploy Instructions — Owner Emails, Zip Downloads & Minimum Price

Deploy instructions for the owner (Nico). All Edge Function updates must be
applied through Lovable's deploy tools, not the CLI.

---

## 0. Apply migrations FIRST — required before any function deploy

Two migrations must be applied to the production database **before** deploying
any edge function. Functions that read or write the new columns will error or
silently drop data if the columns do not exist.

| File | Adds |
|---|---|
| `supabase/migrations/20261118000001_order_urgency_shipby.sql` | `urgency text`, `ship_by_date text` |
| `supabase/migrations/20261118000002_order_payment_breakdown.sql` | `min_adj_cents integer`, `express_cents integer`, `promo_code text`, `promo_pct integer`, `promo_discount_cents integer` |

Apply them in Lovable → Supabase → SQL Editor (or the Migrations tab). Do
**not** proceed to Section 1 until both are applied.

Quick verification query — must return exactly 7 rows:

```sql
SELECT column_name
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name   = 'orders'
  AND column_name  IN (
    'urgency', 'ship_by_date',
    'min_adj_cents', 'express_cents',
    'promo_code', 'promo_pct', 'promo_discount_cents'
  )
ORDER BY column_name;
```

## 1. Edge Function updates

Deploy these functions through **Lovable → Supabase → Edge Functions**, exactly
as they appear on the `main` branch:

### `order-files-zip`

Serves zip archives of order or quote files. Accepts two auth paths:

- **Admin panel** — called with the signed-in user's JWT (`Authorization: Bearer <token>`). No special key needed; Supabase validates the token.
- **Email link** — a signed URL generated server-side by `send-order-confirmation`:
  ```
  /functions/v1/order-files-zip?order_number=123&exp=1700000000&sig=<hex>
  ```
  `sig` is HMAC-SHA256 of `"order.<order_number>.<exp>"` keyed by `SUPABASE_SERVICE_ROLE_KEY`, computed inside the edge function at email-send time — **not in the browser**.

### `send-order-confirmation`

New owner email design with Dimension3D wordmark, gradient header, order details
table, payment breakdown, and a 30-day signed zip download link. The signed URL
is generated by calling `signOrderZipUrl` inside this function; no secret
leaves the server.

### `send-quote-request`

Same new owner email design. No zip link (quote files are not packaged at upload
time).

### `create-instant-checkout`

Minimum order is **9,90 €** (`EST.minimumEur: 9.9`). The constant is kept in
sync with the front end by `scripts/check-estimator-sync.mjs`, which runs as a
pre-build check. Both files were updated together.

### `stripe-webhook`

On `checkout.session.completed` for instant orders, stores:
- `total_paid_cents = session.amount_total` (full amount charged, including shipping, after any promo)
- `urgency`, `express_cents`, `min_adj_cents`, `promo_code`, `promo_pct`, `promo_discount_cents` from the checkout session metadata

These back the "Qué ha pagado el cliente" panel in the admin order card.

## 2. What to test after deploy

### Signed zip link (order email)
1. Find the most recent order that has uploaded files (`file_paths` is not empty).
2. Trigger `send-order-confirmation` for that order (or use an email already received).
3. Click **Descargar archivos ZIP** in the owner email.
4. The browser should download `pedido-<number>-files.zip` without an auth error.
5. Confirm the zip contains the uploaded STL/3MF files.

### Admin panel zip button
Works via JWT auth. Test by opening the admin panel, finding an order with files,
and clicking **Descargar archivos (.zip)**.

### Minimum order price
1. Upload any file to the estimator.
2. The price should floor at **9,90 €** (not 10,00 €).
